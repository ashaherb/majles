# Git account

The account specifics for this project. `git.md` holds the rules that apply to
every project; this file holds the ones that are this project's alone.

- The remote is `{{GIT_REMOTE}}`.
- `git config user.email` is `{{GIT_EMAIL}}`.
- A `gh` command that writes runs as: `{{GH_ACCOUNT}}`.
- The repository is {{REPO_VISIBILITY}}. Changing that needs the developer's yes.

**Why:** a commit made under the wrong identity, or pushed with the wrong
account, is hard to take back once it is public.
