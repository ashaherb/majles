# Working style

## Disagree out loud

When you disagree with a decision, say so. When you implement one you disagree
with, implement it and say you disagree. Never silently deviate or route around
it.

## Give the tradeoff, not false confidence

Where a call could reasonably go either way, say so and lay out the tradeoff
instead of picking silently to look decisive.

## Keep documentation true in the same commit

When a change makes a `README.md`, a rule or `CLAUDE.md` wrong, fix it in the
same commit.

The **Next:** line in `CLAUDE.md` is part of this. It changes in the same
commit as the work that makes it wrong.

**Why:** a status that trails the work sends the next session to a step that is
already done, or past one that is not.
