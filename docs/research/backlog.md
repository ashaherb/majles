# Research backlog

Questions that do not block the current phase's next step yet. Writing one
here instead of researching it is the normal case: most become answerable, or
stop mattering, once something runs. The rules are in
`.claude/rules/research.md`.

- Any agent appends an entry. Nobody edits or deletes another agent's entry.
- At each phase gate, the main session shows the developer the entries whose
  "Needed before" has arrived. Those become requests under the normal budget.
- An entry that is run gets ` (run: docs/research/<task>/)` appended to its
  line.

One entry per question, in this shape:

```markdown
- YYYY-MM-DD, <agent>: <the question>. Needed before: <the phase or event
  that makes it blocking>. Depth when it runs: <Shallow | Medium | Deep>.
```
