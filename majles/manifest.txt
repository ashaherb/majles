#   shared  owned by Majles. `majles sync` keeps projects identical to it.
#           A shared file must never contain a {{PLACEHOLDER}}.
#   once    a template copied when the project or module is created. The project
#           owns it from then on, and sync never touches it again.
#
# `src -> dest` when the file lands somewhere else in the project.
# New projects get [core] and [ui]. The others are added with `majles enable`.
